How to read the Atlas

Methodology

The Atlas separates project research from project geography. A project can be well documented while its exact map geometry is still unresolved.

Verified fact

Stored from reviewed public records and displayed with source links.

Research confidence

How strongly the reviewed record supports the project summary.

Geographic confidence

How precisely the project location, parcel, corridor, or service area is established.

Unknown means unknown

Missing dates, spending, geometry, or outcomes remain visible as unresolved rather than being inferred.
